# ReadX 界面尺寸约定

新界面和修改过的公共组件使用 `apps/web/src/index.css` 中的尺寸 token。颜色仍由现有主题 token 控制。

| 用途 | token | 档位 |
| --- | --- | --- |
| 间距 | `--space-1/2/3/4/5/6/8` | 4 / 8 / 12 / 16 / 20 / 24 / 32px |
| 字号 | `--type-xs/sm/md/lg/xl/2xl` | 10 / 12 / 14 / 16 / 20 / 24px |
| 圆角 | `--radius-sm/md/lg/xl/pill` | 4 / 8 / 12 / 16 / 999px |
| 顶栏 | `--bar-height` | 64px |

旧的 `--radius-card` 暂作兼容；修改组件时改用以上圆角档位。固定尺寸（如图标宽度、面板最小宽度）按组件需求单独设置。

视口断点统一为 **1200、900、760、520px**。CSS 媒体查询使用这些边界；`@theme` 的 `--breakpoint-sm/md/lg/xl` 与它们对应。容器查询按组件自身宽度设置，不属于视口断点。桌面窗口目前最小宽度为 1100px，因此 900px 以下的布局用于浏览器运行和开发预览。
