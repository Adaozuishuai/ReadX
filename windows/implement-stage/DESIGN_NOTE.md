# Research Workspace 设计优化

[可编辑 Figma 设计稿](https://www.figma.com/design/pZPZm5BfxgqK8Bq9yp49LV?node-id=2-305)

- 书库、阅读日历、导入面板对应三个独立画板；文字、布局和热力图格子保持可编辑。
- 沿用 Instrument Sans 与系统中文字体，统一暖白画布、墨绿强调色和分层表面；支持浅色、深色、纸张与系统主题。
- 全局导航整合导入入口。书库使用当前列表的真实数量概览，双语文献卡片与推荐栏共用圆角和间距规范。
- 文献状态显示明确标签，移除按状态猜测的 45% 阅读进度。
- 导入保留投篮交互，增加键盘可操作的文件选择和「直接导入」入口，复用已有请求互斥、取消及进度逻辑。
- 阅读日历的月份与周列对齐；说明统计仅覆盖每篇文献最新阅读位置。
- 窄屏切换为图标侧栏和主题选择器；推荐栏可作为浮层打开。

验证：前端类型检查与生产构建、`npm run test:import`；使用模拟文献数据检查 1440px、1024px、640px 布局和三种主题。浏览器回归不调用 AI。
