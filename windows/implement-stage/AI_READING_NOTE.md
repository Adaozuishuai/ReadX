## 默认的原页精读流程

- 五重奏默认使用 paper-reader 流程。先结合每页文字、完整原页和上下重叠放大图通读论文；随后重新观察同一组图像，核对公式上下标、分母、运算、编号及表格的表头、数值、单位和脚注。文本层乱码不再作为删除可见公式的理由。
- 阅读器使用 PDF.js 顺序渲染每页三张 PNG，最长边不超过 2048；通过 POST /v1/ai/paper-page 一页一页提交。每页初读先落库，再复核。停止会取消活动请求；再次生成复用已完成的原页缓存，只重读未完成部分。
- 缓存按正文、PDF 指纹、阅读版本、渠道、模型及推理等级隔离，原页图像哈希随笔记保存。图片附件保持临时，不写入精读记录或登录目录。缓存以 app_state 独立行保存，避免页面越多、每次写入和打开五重奏越慢；清空对应论文时同步移除阅读缓存和历史。
- 汇总材料覆盖每个实际页面。长论文按完整页分组、分层串联，不截取前 50,000 字后丢弃尾页；分组不切断单页公式或表格。
- 图表逐张观察、结合全文分配唯一步骤和小节；正文中由模型给出真实目录 ID 的嵌入位置。程序只接纳该小节的有效 ID、去重，并在对应段落中显示高清原图。图表分析失败只记具体条目，不阻塞正文或其余图片。
- 正文直接生成中文 Markdown，LaTeX 直接作为数学内容处理；模型不再需要先把整份正文和公式序列化成 JSON。每个小节生成后立即保存并通过进度流显示，再对照逐页阅读材料修正公式、数据、物理页码与训练/推理解释。复核未完成时保留初稿及具体小节状态。
- 整节正文存为 narrative 和 narrativeSections。旧 value 继续兼容现有记录；新记录的 value 最初就是可读正文。实验配置、结果数据和复现索引在正文已保存后单独整理；只有证据校验通过或局部修剪后通过的索引才写入 value。索引格式/摘录出错不删除或否定 narrative。
- 原有严格 JSON 修复、evidenceID 原文回填、逐字证据校验与本地修剪保留用于结构化索引和旧接口。它们不再充当新正文的保存门禁。视觉识别不是逐字证据匹配；页面读取和二次观察完成也不代表科学内容已获得独立正确性证明。
- 重新生成前保存上一版记录到本机历史行；中途停止保留已经写入的页面和小节。相同阅读材料的未完成任务可复用已完成的小节。无法读取的页、未附入的原图、未完成的小节只在具体任务状态中列明，不加通用证据声明或核验流程横幅。
- 保留点击 Page 回原文、单节生成、生成剩余项、停止、复制、导出、结果数据对比与复现行动清单。正文和公式采用安全的 React 文本/Markdown 与 KaTeX 渲染，不执行模型 HTML 或任意图片地址。
- 保留步骤导航与正文两栏、正文顶部模型选择、段落内真实图表及底部图表区选区管理。人工阅读检查、图表侧栏、独立分析图表按钮和通用说明文案继续删除。

## 模型与推理强度

`POST /v1/ai/models` 对 Codex 使用原生 app-server 的 `model/list` 读取目录及每个模型支持的推理等级，不硬编码模型清单。目录支持刷新和短时缓存。

`PUT /v1/ai/settings` 保存 `model` 与 `reasoningEffort`；服务端校验二者兼容性。对话输入区和精读配置区共享选择，自动保存后用于后续请求。切换模型会回到该模型默认推理强度。

实际推理仍使用已连接的 Codex Desktop 自带程序，传入 `-m` 和 `model_reasoning_effort`，不要求另装 CLI。高推理强度有较长、可取消的请求期限。对话与精读记录保存本次配置来源，切换配置不会重标旧回答。

## 对话与本机数据

对话输入区按用户提供的 Codex 截图调整：大圆角、上层自动增高输入、下层左侧加号与论文上下文，右侧合并的模型/推理等级入口、麦克风与绿色圆形操作按钮。空输入的语音按钮在浏览器支持语音识别时填充草稿，有文字时切换为发送；回答期间切换为停止。语音不会自动发送消息。左侧展示真实论文上下文，不显示不存在的“完全访问”权限。加号支持当前论文引用、文本附件和跳转五重奏；当前论文标题及引用段落按需展开，不固定占据输入框上部。

语音识别由浏览器能力决定；不支持时禁用语音入口。文本附件只在读者发送后加入当前问题，限制单个文件 64 KB、合计 16000 字符、最多 3 个文件。对话模型菜单从实际 Codex 目录生成，使用带选中对勾、悬停与键盘导航的列表。推理强度为离散滑杆，档位随所选模型变化；拖动预览，松手或键盘选择后保存，可恢复模型默认强度。点击已选模型不重置现有推理强度。输入区、选中状态和滑杆统一绑定应用绿色强调色。控件文案使用英文（Model、Reasoning effort、Low/Medium/High 等），强度标签预留固定宽度。保存后直接同步服务端返回的设置，不重新加载模型目录；保存提示仅用于读屏，不撑开弹层，滑杆和恢复默认按钮在强度保存期间保持可操作。连续拖动串行写入，并合并尚未发出的中间值；保留最后选择的预览直至保存完成，失败才回退并显示具体错误。发送按钮在设置保存期间保留原图标，避免输入区闪烁。

每篇文献可建立多个对话。完整历史保存在浏览器本机存储；后续模型上下文只包含完整成功的问题/回答对，再由服务端截取最近记录。停止、失败和未完成回答有明确提示，不作为完整历史传给模型。删除对话可在本次会话内撤销。

不读取或复制 Codex 登录令牌。文档工具访问策略沿用现有集成。新字段兼容旧精读 JSON，无需数据库结构迁移。
