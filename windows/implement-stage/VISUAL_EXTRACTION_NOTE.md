# 图表定位与原页校正

## 本轮定位的原因

1. 图注上方搜索的扫描方向写成了向下，导致漏掉图注上方的图，随后误取图注下方正文。
2. 全页排序后的文本行按数组相邻位置拼图注，遇到另一栏会提前结束，或跳过另一栏的图注。
3. 只处理较大栅格图片，部分小面板被提前丢弃；单个图像对象会直接覆盖整图裁切范围，矢量模块、坐标轴和其他子图因此遗漏。
4. 空白扫描没有相邻图注、正文段落边界约束，可能把前一张表一起裁入；失败时仍导出大面积猜测区域。
5. 图表仅显示所属精读步骤，用户难以分清未识别、未匹配步骤和裁切失败。

## 当前行为

- 图注按同栏空间邻接拼接，过滤行首的正文引用，表头不并入图注；短而居中的表题可展开到跨栏范围。
- 几何线索覆盖普通图像、重复与分组图像、矢量路径及 Form 裁剪框；连接的面板合并后再关联图注，不把独立图像对象自动当成整图。
- 上方/下方扫描分别采用正确方向；搜索范围受相邻图注与正文边界约束。存在完整图形组时保留该组及邻近标签，避免空白扫描越过间隔吞入上一张表。
- 无可靠边界时显示待确认或裁切失败，不导出整块猜测区域冒充成功。待确认、失败和用户忽略的候选不送入精读图表目录。
- 「全部图表」独立于精读归类；正文提及但尚未定位的编号提供页码入口，不声称这些编号一定是本论文遗漏的图表。
- 「校正范围」与「补选遗漏图表」提供原 PDF 页面拖框、页码、类型、步骤和百分比边界微调；高清裁切仍从原 PDF 重新渲染。
- 人工选区和忽略列表按 PDF 指纹存入本机浏览器存储；重新识别保留人工范围。自动候选可忽略并恢复，人工校正可恢复自动范围。
- 有效裁图用于五重奏的实际图片分析，AI 结合原文选择步骤与小节。统一归类写入论文记录，正文中直接嵌入对应图表与解读；选区变化时旧图表分析失效。无需勾选人工阅读检查。
