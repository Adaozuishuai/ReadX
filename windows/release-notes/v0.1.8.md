ReadX v0.1.8 improves live translation, PDF reading, and library workflows.

### What's new

- Show translated page content as soon as each segment is ready, while LeePDF continues processing the rest of the document.
- Start or resume processing from a library item, and retranslate without reusing completed translation cache entries.
- Generate the five deep-reading sections independently while reusing the paper context prepared during import.
- Highlight OCR-detected formulas, ask the assistant about highlighted passages, and jump to the full paragraph in the parallel translation view.
- Improve PDF heading order for two-column papers and keep the selected heading focused.
- Let the AI assistant read images attached to a conversation.
- Remove imported library copies when permanently emptying the trash, while keeping the user's original files.
- Render formatted HTML release notes correctly in the in-app update dialog.

### Downloads

- Windows: `ReadX-Setup-0.1.8.exe`
- macOS: download the DMG matching your Mac's architecture. macOS packages are unsigned and may require approval in Privacy & Security on first launch.
