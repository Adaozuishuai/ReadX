## ReadX v0.1.3

### 新功能

- 首页新增检查更新。发现新版后会展示本次功能说明，可选择立即更新或暂不更新；下载完成后重启即可安装，无需手动删除旧版。
- 精读五重奏的五个部分可并行生成，并复用导入时建立的论文上下文，减少重复分析等待。
- 书库支持对缺少译文或需要重译的论文直接发起重新翻译。
- 阅读器支持连续滚动浏览原文和译文；原文跳转译文仅在中英对照模式触发。

### 改进与修复

- Windows PDF 导入改用 Lee 处理链路，并对齐 OCR、翻译段落计数与处理进度。
- 修复精读表格横向溢出及页码标记被挤出的布局问题。
- 改善精读记录生成状态，正文保存后不再因后续索引工作而一直显示生成中。
