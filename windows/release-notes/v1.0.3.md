# ReadX v1.0.3 · Windows x64

### 跨设备同步

- 在全部文档页的同步入口中，选择坚果云 WebDAV 或任意本地同步目录（包括 OneDrive 桌面客户端目录），一键合并书库、阅读进度和笔记。
- 同步采用设备版本记录，能合并不同设备的并发编辑，保留冲突版本。
- 坚果云应用密码加密保存在本机；OneDrive Microsoft 账号直连等待应用 Client ID。

### 阅读与导航

- PDF 选区可创建手写风格页边笔记，记下原文页码和位置；支持拖动、调整大小、编辑、删除及批注面板检索和导出。
- 按住 `Alt` 呼出双层快速轮盘，在个人书库、学术工作台、PPT、LaTeX Studio 和摸鱼工作区之间切换，并打开对应文献、待办或项目。关闭主窗口会最小化到后台。
- 修正学术工作台与阅读日历重复使用同一图标的问题。

### AI 助手与文档处理

- 新增百度千帆、腾讯 TokenHub、腾讯混元、Google Gemini、xAI / Grok、Groq、Mistral AI 和 DeepInfra 服务商预设。
- 改进切换服务商时的密钥状态提示；各服务地址的密钥独立保存。
- 支持从处理面板和任务详情重新提交中断、失败或取消的任务；改进书架封面与处理状态交互。

### Windows 下载

- `ReadX-Setup-1.0.3.exe`：Windows x64 安装包。
- `.exe.blockmap` 与 `latest.yml`：供应用内自动更新使用。
