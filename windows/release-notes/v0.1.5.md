ReadX v0.1.5 brings the latest Windows changes to macOS and improves AI-assisted reading, PDF annotations, and import progress.

### What's new

- Publish Windows and macOS packages together. Download the Windows installer or the macOS DMG whose architecture matches your Mac.
- Finish importing as soon as the translated PDF is saved to the library. Paper memory is prepared in the background, and a **Process** action opens its progress from the library.
- Align Codex model and reasoning controls with the capabilities returned for each model, including Fast mode where available.
- Improve PDF highlight and underline geometry to reduce clipping, overlap, and inconsistent highlight fills.
- Prevent concurrent translation-cache writes from colliding, and improve persisted import-job recovery and progress reporting.

### Platform notes

- macOS builds are currently unsigned. macOS may require confirming the first launch in **System Settings → Privacy & Security**.
- Translation and OCR still require the services configured in ReadX. Codex features require a signed-in Codex Desktop connection.
