ReadX v1.0.0 将论文阅读、LaTeX 写作和本地休闲阅读放进同一个桌面工作区。

### 新功能

- **LaTeX Studio**：新建项目、导入 Overleaf ZIP、编辑真实 `.tex` / `.bib` 文件，并预览本机 TeX 编译的 PDF。
- **对话内确认修改**：直接发送修改要求，AI 在对应回复下生成文件修改卡片。查看修改前后内容，点击「确认修改」才创建快照并保存；取消则保留原文件。输入栏显示「请求批准」。
- **项目源码上下文**：助手结合当前编辑内容和项目源码定位章节，可从 `main.tex` 的引用找到实际文件；保存前核对内容，避免覆盖生成期间的新编辑。
- **独立模型设置**：LaTeX 可使用自己的 HTTP 模型渠道，支持拉取、搜索和选择模型，配置同步显示在助手标题与输入栏。
- **更灵活的写作布局**：目录支持拖宽和更大字号，诊断列表可隐藏，编译修复与源码快照默认折叠。
- **编译与诊断改进**：沿用上次构建的辅助文件，按需多趟编译；错误、警告和诊断列表保持一致，未确定的位置不猜测。
- **淡绿色漫画窗帘**：点击顶部挂件，在科研与摸鱼界面之间合幕换景。采用平涂色块、描边褶皱、扇形帘头和轻微网点；挂件可沿顶部拖动并记住位置。
- **本地小说与漫画书架**：支持 TXT、EPUB、图片和 CBZ；找书入口支持 Project Gutenberg，以及兼容的 Legado 中文连载书源。

### Windows 下载

- 安装包：`ReadX-Setup-1.0.0.exe`，适用于 Windows x64。
- `.exe.blockmap` 与 `latest.yml` 为应用内自动更新所需文件，手动安装只需下载 `.exe`。

LaTeX 编译需要本机已安装的 TeX 发行版。AI 问答或修改会把相关项目源码上下文发送给你配置的模型服务，确认后的文件保存与 TeX 编译在本机完成。
