ReadX v1.0.2 · Windows x64

### 学术工作台

- 新增科研日常、学业看板和资讯追踪，从侧栏进入学术工作台。
- 管理研究任务、优先级、截止日期和研究日志，记录培养进度、发表论文及毕业要求。
- 聚合 arXiv、期刊 RSS 和科技周刊，支持标题翻译与稍后阅读。

### 专注计时

- 番茄钟采用白底绿字，支持正计时与倒计时。
- 离开工作台后，顶部显示可拖动的数字计时牌及沙漏动画；点击沙漏暂停或继续，点击时间返回工作台。
- 倒计时结束自动记录研究日志，正计时可手动结束并记录实际专注时长。

### 导入与书架

- 支持从本机 Zotero 资料库浏览分类、搜索文献并多选 PDF，携带题录信息加入导入队列。
- 批量导入最多同时处理 14 篇，支持递归导入文件夹内的 PDF / EPUB。
- 批量导入新增多文件连续投篮动画，与上传处理同步进行。
- 分类书架增加独立封面；书架页面只显示已创建的分类。
- 精简导入及工作台说明文案，修复更新界面“立即更新”按钮的绿色样式。

### Windows 下载

- `ReadX-Setup-1.0.2.exe`：Windows x64 安装包。
- `.exe.blockmap` 与 `latest.yml`：供应用内自动更新使用，手动安装只需下载 `.exe`。

从 Zotero 导入时，请保持 Zotero 7 或更新版本运行，并在「设置 → 高级」中启用「允许此计算机上的其他应用程序与 Zotero 通信」。
