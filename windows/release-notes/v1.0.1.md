ReadX v1.0.1 完善译文任务、论文阅读和找书体验。作者与 Windows 安装程序发布者署名为 **Lee**。

### 本次 Windows 安装包更新（2026-10-24）

- 修复重新翻译复用论文记忆后，书库“处理”按钮仍持续显示的问题。
- 改进精读图表归属识别与候选图使用，减少图表分析未进入正文的情况。
- 调整演示稿版面、圆角卡片和文字布局，保持预览与 PPTX 导出一致。
- 摸鱼界面增加 2048、倒计时和阅读周报，并完善小说与漫画阅读记录。

### 翻译与阅读

- 修复重新翻译已生成 PDF 后，渲染阶段仍持续显示“处理中”的问题；已完成的旧任务会根据保存的产物校正状态。
- 区分译文块、段落缓存与页面进度，避免显示不一致的计数和单位。
- 修复重新打开面板后无法取消重新翻译、任务失败后其他阶段继续转圈，以及重跑覆盖任务历史的问题。
- 改进 PDF 段落选择、目录定位、译文展示与阅读界面布局。

### 找书与本地阅读

- 整合书源检索、详情、下载和导入流程，支持 Project Gutenberg、OPDS 和配置后的 Z-Library 服务。
- 完善下载取消与共享任务处理，改进小说阅读和漫画双页翻页。

### 稳定性

- 修复恢复文档与清空回收站并发时可能误删文档的问题。
- 完善后台实验配置任务、流式响应及元数据并发更新。
- 改进 LaTeX 编译诊断与辅助文件复用，统一弹窗与交互样式。

### Windows 下载

- `ReadX-Setup-1.0.1.exe`：Windows x64 安装包，本地构建。
- `.exe.blockmap` 与 `latest.yml`：应用内自动更新文件，手动安装只需下载 `.exe`。
