# NAF: Neural Attenuation Fields for Sparse-View CBCT Reconstruction

> Zha, Zhang, Li。原文：[library/2022-NAF-2209.14540.pdf](library/2022-NAF-2209.14540.pdf)；[arXiv 2209.14540](https://arxiv.org/abs/2209.14540)。

## 一句话总结
把衰减系数表示成三维坐标的连续函数（哈希编码 + 小 MLP），沿光线按 Beer 定律合成投影、与实测投影做 L2，单例自监督优化 10–40 分钟，在 50 views 的五个数据集上全面超过 FDK、SART、ASD-POCS、IntraTomo3D，且不需要任何外部训练数据。

## 1. 问题设定
- 任务与动机：sparse-view CBCT 重建。投影少（剂量低、扫描快），传统解析/迭代方法在欠定条件下伪影严重。
- 扫描几何 / 投影数量 / 角度范围：圆锥束。模拟实验 50 views、0–180° 等角间隔；真实数据为 GE C-arm 采集的 582 张透视投影（500×500，−103°–93°），从中取 50 张参与重建（Sec. 3.1 Data）。
- 数据：模拟 4 组——chest（LIDC-IDRI，128³）、jaw 与 foot（Open Scientific Visualization Datasets，256³）、abdomen（512×512×463），投影用 TIGRE 工具箱生成并加 3% 噪声；真实 1 组——主动脉假体，真值 512×512×510（Sec. 3.1 Data）。

## 2. 方法核心
按「体积表示 → 生成投影 → 与实测比较 → 优化」（Fig. 1）：

- **体积表示**（Sec. 2.2）：μ(x) = f_Φ(g_Θ(x))。g 是 multiresolution hash encoding（instant-NGP）：L 层网格、每层可训练特征表大小 T，角点哈希查找后线性插值，各层输出拼接为 32 维——对比频率编码的 256+ 维。f 是 4 层全连接：前三层 32 通道 + ReLU，输入跳连拼接至第二层激活，末层 1 神经元 + sigmoid 输出衰减系数。整体比 IntraTomo 的 6 层 256 通道 MLP 小约 10×（Sec. 2.2 Attenuation coefficient prediction）。
- **投影合成**（Sec. 2.2 Attenuation synthesis）：沿每条光线分层采样 N 个点（N 取得比体素网格尺寸大，保证每个穿越的体素至少 1 个样本；128³ 用 N=192），按 Beer 定律离散化：I = I₀·exp(−Σᵢ μᵢ δᵢ)，δᵢ = ‖pᵢ₊₁ − pᵢ‖ 为相邻采样点距离。
- **损失 / 优化**（Sec. 2.3 + 3.1 Implementation details）：L = Σ_{r∈B} ‖I_real(r) − I_syn(r)‖²，哈希编码 Θ 与 MLP Φ 联合优化；Adam，学习率 1×10⁻³ 阶梯降到 1×10⁻⁴，每批 2048 条光线。训练完逐坐标查询 MLP，输出离散体素网格。
- **关键设计论据**：哈希编码利用人体器官的平滑性与稀疏性，比频率域编码更高效且性能更好，同时避免纯 MLP 的频谱偏差（Sec. 1 + Sec. 2.2 Position encoding）。
- **值得校准的一点**：原文**没有**任何角度渐进/课程策略，投影就是等角间隔取 50 张参与训练——网上流传的"progressive angles 版 NAF"不是这篇的做法。

## 3. 实验可信度
- 对比条件一致：所有方法在同一批 50-view 数据上比较（Sec. 3.1 Baselines）。FDK 解析法、SART / ASD-POCS 迭代法（ASD-POCS 带 TV 正则）、IntraTomo3D 自监督学习法。主表 Tab. 2 五个数据集 NAF 全部第一：chest 33.05/.96，jaw 34.14/.94，foot 31.63/.94，abdomen 34.45/.95，aorta 30.34/.88；abdomen 上比第二名 SART 高 3.07 dB。Fig. 4 在 abdomen 上做 views 消融，大多数 view 数下最优——注意是"大多数"而非全部，哪个区间被反超值得回查。
- 细节丢失：显存未报告；3% 噪声的具体模型（加性高斯还是泊松）对真实场景的代表性存疑；哈希表大小 T 对 512³ 数据的容量是否充足未讨论；投影合成是连续衰减过程的离散近似（作者承认的近似，Sec. 2.2）。
- 时间 / 显存：10–40 分钟/例（Sec. 1 末 + Sec. 3.2 Time），单张 RTX 3090，约为 IntraTomo3D（>1 h）的 1/3；显存未报告。
- 我存疑的结论："无需训练数据"的代价是每例都要重新优化 10–40 分钟；且对比里没有任何监督式重建网络——这是自监督赛道内部的比较，与监督方法的天花板差距文中未讨论。

## 4. 研究启发
- 值得复现：整条「INR + 可微投影合成 + 投影域 L2」管线小而完整，官方代码在 [Ruyi-Zha/naf_cbct](https://github.com/Ruyi-Zha/naf_cbct)，适合作为后续所有方法的 baseline 骨架；重点复算"哈希编码 vs 频率编码"这个论断——它支撑了效率主张。
- 有待验证：显存峰值（决定 512³+ 真实尺寸能否单卡放下）；极稀疏（<20 views）下限——没有外部先验时是否崩溃；金属伪影/更高噪声下的鲁棒性。
- 与已读论文的联系：**本库第一篇，基准锚点**。后续每篇都先对照三件事找差异：① 表示比"连续函数"强在哪；② 监督信号除投影域 L2 外还加了什么；③ 先验/训练数据从哪来、换来了多少指标。
