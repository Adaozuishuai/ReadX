# PRD 4.10 复现准备：实施与验收

日期：2026-10-02。主产品：macOS SwiftUI / PDFKit。样本：公开 NAF PDF，arXiv 2209.14540，11 页。配置模型名 deepseek-flash，实际模型权重版本未知。模型请求在临时数据目录运行，未发送正式研究画像、Ideas、个人核对记录或私有笔记；API Key 不写入输出。

## 已实现

- 资源、环境、训练成本、关键缺失、风险五类结构化分析。论文报告字段须有同页逐字摘录，字段数字须由该摘录支持；未知字段使用明确的空页码/空摘录格式。分析与行动作为 AI 推断/建议显示，不作为已验证结论。
- 原文页码跳转与摘录高亮；从核对行动创建 Planned Idea，保留来源标识。未知项不生成伪造的论文事实附件。
- 人工状态：待核对 / 已核对 / 受阻。已核对与受阻必须填写结论或原因；编辑显示未保存状态，保存失败不更新统计。
- 核对记录按分析内容 SHA-256 分版本保存；不同分析不继承旧记录。原分析快照与个人记录共同保留，研究资产 JSON schema 1.3 导出包含这些内容；支持当前版 Markdown 清单导出。
- 损坏的清单文件或无法读取的目录阻止覆盖；旧 ReadingFile 没有复现字段时仍可加载。重新生成分析保留旧解析历史。

`native/build-app.sh`：发布编译、打包、安装通过。独立界面验收使用相同发布二进制与 `/tmp/cbct-prd-ui`，正式资产不受影响。

UI 已确认：展示真实模型的 10 个条目；空说明不能保存“已核对”；填写明确核对范围后保存，统计为 1/10；重开应用仍显示该状态。核对范围仅为 Page 1 的论文代码链接声明，未访问仓库或运行代码。未知的训练终止条件可转成 Planned Idea，只有研究建议附件。Markdown 导出含原文、未知标识、AI 分析、行动和人工记录，实际导出副本为 [REPRODUCTION-checklist.md](REPRODUCTION-checklist.md)。

跨页问题的修复没有放宽校验。错误诊断给出所标页可匹配的逐字片段，帮助模型重写事实与引用；不自动接受或替换错误摘录。失败样本仍保留。

对报告字段的核对范围：Page 1 代码链接声明；Page 6 五数据集、PyTorch、RTX 3090、hash encoder 引用超参、PSNR/SSIM；Page 8 CUDA 加速；Page 3 10–40 分钟重建时间。终止条件和完整投影几何保持未知，只表示当前材料未找到。

**人工审阅发现的剩余问题：** `reproduction-v4` 成本分析把 10–40 分钟标为“训练时间”，原句报告的是重建时间；其“未说明硬件配置”表述过宽，Page 6 已明确 RTX 3090，真正缺少的是分数据集耗时、迭代/收敛协议等细节。这些问题未被字面摘录/数字校验识别。几何缺失项的“合理设置”建议也不能视为复现原协议，只能作为另行标注假设的实验。

因此，仅接受软件流程和结构化证据校验通过，**不接受整个分析已正确或已证明可复现**。AI 推断、缺失判断和行动仍需研究者审阅。单篇样本不代表总体正确率。
