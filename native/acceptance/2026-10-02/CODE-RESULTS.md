校验拒绝虚构文件/行号、超范围、改动运算符的代码摘录、无论文原文依据或超范围置信度。人工核对必须另写说明，重新映射会重置当前核对标记；旧快照归档。界面显示 commit、已读范围、文件文本与固定版本链接，可回 PDF 核对论文依据。

语义尚待审阅：论文 ReLU 与代码 LeakyReLU、论文 batch 2048 与配置 1024、公式与具体积分实现的对应、sum/mean 约定。不能仅据这些差异判定仓库有错误。传给映射模型的文件摘录比已读快照短，范围差异需要继续改进展示。

## 结果

- `results-v1/`：主表数值结构通过，但 PSNR 单位判定与泛化/时间措辞有错误。
- `results-v2/`：自动修正后仍有 header 的数字缺少对应摘录，拒绝接受，失败原样保留。
- `results-v3/`：57 秒，结构通过；5 个 PSNR 列使用 Page 6 的 dB 单位证据，SSIM 不强行补单位。

Page 7 Table 2 的五方法 × 五部位 × PSNR/SSIM，共 50 个数值，逐项与原 PDF 图像核对一致。列为 Chest/Jaw/Foot/Abdomen/Aorta。NAF Abdomen PSNR 34.45 与 SART 31.38 的差值为 3.07 dB；原生界面选取相应方法/列后显示输入、差值，并能跳到 Page 7 高亮所用行。这个运算不推导显著性。dB/PSNR 的百分比提升关闭；零基准或未知单位也关闭相对差。

仍需改进：完整 views/几何/数据划分协议与表格的关联、多论文表头/单位/列语义验收；作者说 statistically significant 不代表本文系统已运行统计检验。公式运算符抽取缺失仍需原 PDF/视觉复核。
